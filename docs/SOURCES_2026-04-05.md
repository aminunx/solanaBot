## Source Notes
- `api.jup.ag` is the primary Jupiter endpoint and may require `x-api-key`.
- `lite-api.jup.ag` is used only as a fallback while no API key is configured.
- Raydium quote construction is based on the current official `swap-base-in` endpoint.
- Orca pool discovery uses the current Orca public API and quote construction uses the current official Whirlpools SDK.

## Source Policy
Only current official product documentation is accepted for this repository. Old blog posts, archived SDK assumptions, and unauthenticated third-party tutorials are excluded from design decisions.
